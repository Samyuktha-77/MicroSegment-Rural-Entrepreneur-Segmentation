ABOUT THE PROJECT

Data-driven segmentation, not credit scoring.

MicroSegment is an academic machine learning project that applies unsupervised K-Means clustering to historical India-focused Kiva loan records. It explores similarities in loan amount, loan term, sector and repayment interval.

The dataset is historical and does not verify that every borrower is rural or that every loan represents a business. Cluster assignments are not credit scores, repayment predictions or loan approval recommendations.
